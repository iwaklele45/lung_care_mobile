# AGENTS.md

## Tooling
- FVM is required. Flutter version pinned in `.fvmrc` (3.41.9).
- Prefix all Flutter commands with `fvm`: `fvm flutter pub get`, `fvm flutter run`, `fvm flutter analyze`, `fvm flutter test`.
- Codegen: `flutter pub run build_runner build --delete-conflicting-outputs` (no `fvm` prefix — build_runner resolves via the FVM-managed SDK).
- Generated assets output to `lib/gen/` (generated by `flutter_gen_runner`, not checked in).

## Commands
- **Install**: `fvm flutter pub get`
- **Codegen**: `flutter pub run build_runner build --delete-conflicting-outputs`
- **Lint/analyze**: `fvm flutter analyze`
- **Test**: `fvm flutter test`
- **Run**: `fvm flutter run`
- **Build APK**: `fvm flutter build apk --release`

## Architecture
- Clean Architecture under `lib/src/`: `core/`, `data/`, `domain/`, `presentation/`.
- Two state management packages coexist: **flutter_bloc** (auth + home BLoCs) and **provider** (LocaleProvider for i18n).
- BLoC conventions: one directory per feature under `presentation/bloc/`, each with `*_bloc.dart`, `*_event.dart`, `*_state.dart`.
- All GoRouter routes are defined **inline in `lib/main.dart`** — there is no separate router file.
- Repository pattern: abstract contracts in `domain/repositories/`, implementations in `data/repositories/`.

## Firebase & Auth
- Firebase init in `lib/main.dart` with `Firebase.initializeApp()` before `runApp`.
- **App Check is completely disabled** (commented out in `main.dart:42-46`) to support sideloaded APK for Tugas Akhir. Do not re-enable without understanding this constraint.
- Auth flow: `AuthBloc` dispatches events (e.g., `AuthSignInRequested`, `CheckAuthStatusEvent`). UI pages under `presentation/pages/auth/`.
- Firebase config at `lib/firebase_options.dart` (auto-generated, do not edit by hand).

## Internationalization
- i18n files in `lib/l10n/`. Supports Indonesian and English.
- LocaleProvider extends `ChangeNotifier` and is injected at root via `ChangeNotifierProvider`.

## Assets
- Assets must be listed in `pubspec.yaml` → `flutter → assets` before codegen.
- Use typed access via generated classes: `Assets.icons.foo.image(...)` for raster, `Assets.icons.foo.svg(...)` for SVG.

## Testing
- Single widget test at `test/widget_test.dart`. It instantiates `MyApp` directly (requires LocaleProvider).
- Tests that import `main.dart` need Firebase initialized — widget tests may fail without Firebase emulation.
